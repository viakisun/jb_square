# JB SQUARE 태그 시스템 가이드

## 개요

JB SQUARE 백오피스 시스템의 태그는 공고를 분류하고 사용자가 원하는 정보를 쉽게 찾을 수 있도록 돕는 라벨입니다. 총 65개의 태그가 8개의 카테고리로 분류되어 있으며, 3가지 바이오 분류 색상과 기본 회색으로 시각적으로 구분됩니다.

## 태그 통계

- 전체 태그: 65개
- 활성화된 태그: 65개
- 태그 카테고리: 8개
- 색상 스킴: 4개

## 태그 관리

### 태그 생성

1. 콘텐츠 관리 페이지로 이동
2. 새 태그 추가 버튼 클릭
3. 태그 정보 입력
   - 이름: 사용자에게 표시될 태그명
   - 슬러그: URL에 사용될 영문 식별자 (예: red-bio)
   - 설명: 태그에 대한 간단한 설명
   - 카테고리: bio_field, tech_field, support_type 등
   - 색상: 배경색 (색상 프리셋 선택 또는 직접 입력)
   - 아이콘: 태그 앞 아이콘 (선택 사항)
   - 표시 순서: 목록에서 표시될 순서 (숫자가 낮을수록 먼저 표시)
   - 활성화 상태: 사용 여부 (비활성화 시 사용자에게 표시 안 됨)
4. 저장 버튼으로 생성

### 태그 수정

1. 태그 목록에서 수정할 태그 클릭
2. 정보 수정
3. 저장 버튼으로 변경사항 적용

### 태그 순서 변경

태그 목록에서 드래그 앤 드롭으로 순서를 변경할 수 있습니다. 변경된 순서는 자동으로 저장되며, 사용자 화면에 즉시 반영됩니다.

### 태그 삭제

태그를 삭제하면 해당 태그가 적용된 모든 공고에서 태그가 제거됩니다. 삭제 전 사용 중인 공고가 있는지 확인하십시오.

- 사용 중인 태그: 삭제 시 경고 메시지 표시
- 사용되지 않는 태그: 즉시 삭제 가능

## 태그 적용 가이드

### 공고별 권장 태그 조합

#### R&D 과제 공고
- 필수: R&D
- 바이오 분야: 신약개발, 바이오의약품, 진단기술 등
- 기술 분야: AI/빅데이터, 디지털헬스 등
- 주관 부처/기관: 과기정통부, KEIT, NRF 등
- 지원 대상: 중소기업, 스타트업 등

#### 사업화 지원 공고
- 필수: 사업화
- 바이오 분야: 해당 산업 분야 선택
- 지원 유형: 투자유치, 인증지원 등
- 주관 기관: KIAT, 창업진흥원 등
- 지역: 전북, 수도권 등

#### 창업 지원 공고
- 필수: 창업
- 지원 대상: 예비창업, 스타트업
- 특화 프로그램: 멘토링, 네트워킹 등
- 주관 기관: 창업진흥원 등
- 지역: 해당 지역 선택

#### 농생명 공고
- 필수: 농생명
- 바이오 분야: 식품바이오, 바이오에너지 등
- 주관 부처: 농식품부
- 기술 분야: 기후테크, 탄소중립 등
- 지원 유형: R&D, 사업화 등

## API 엔드포인트

### 태그 관리 API

```
GET /api/tags
```
전체 태그 목록을 조회합니다.
쿼리 파라미터: is_active, category

```
GET /api/tags/active
```
활성화된 태그만 조회합니다.

```
GET /api/tags/{tag_id}
```
특정 태그의 상세 정보를 조회합니다.

```
POST /api/tags
```
새 태그를 생성합니다.

```
PUT /api/tags/{tag_id}
```
태그를 수정합니다.

```
DELETE /api/tags/{tag_id}
```
태그를 삭제합니다. 사용 중인 태그는 삭제할 수 없습니다.

```
PUT /api/tags/reorder
```
태그 표시 순서를 변경합니다.

```
GET /api/tags/stats/categories
```
사용 중인 태그 카테고리 목록을 조회합니다.

```
GET /api/tags/color-presets
```
색상 프리셋 목록을 조회합니다.
